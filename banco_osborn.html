🧩 Banco de Ideias — Listagem de Osborn

Travou na hora de gerar ideias? Veja como decompor uma solução em atributos e atacar um por um. São exemplos trabalhados a partir das mesmas dores do Banco de Problemas — use como molde, não como cópia.

⚠️ O método é simples: liste os atributos da sua solução (energia, forma, conectividade, cobrança…) e, para cada um, pergunte "e se a gente mudasse isto?". Cada troca é uma ideia nova. Aqui você vê o exercício pronto para 5 conceitos — faça o mesmo com o seu.
