🔍 Como achar uma
boa dor (e de quem)

Antes de inventar a solução, é preciso caçar uma dor real e saber de quem ela é. É o passo que decide se o projeto nasce forte.

⚠️ O erro nº 1

Apaixonar-se pela solução cedo demais

A maioria das startups morre porque constrói algo que ninguém quer. Comece pela dor, não pela ideia.

🧪 5 Porquês

A primeira dor quase nunca é a verdadeira

Pergunte "por quê?" umas cinco vezes até a raiz.

🌱 "Perde safra" → geada → não prevê a tempo → previsão é regional → não há sensor local acessível (a raiz).
🧰 Jobs to Be Done

O cliente "contrata" um produto para um trabalho

Quando [situação], quero [ação], para [resultado].

"Quando há previsão de frio à noite, quero ser avisado com horas de antecedência, para salvar a safra."

🗣️ Entrevista de descoberta

Pergunte sobre o passado, não sobre o futuro

Boas perguntas
"Me conta a última vez que teve esse problema." · "Como resolveu? Quanto custou?"
Evite
"Você compraria isso?" · "Acha minha ideia boa?"
